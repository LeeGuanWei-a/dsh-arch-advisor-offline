# 文档体系参考：GB/T 8567—2006 的 25 类 + 旧版 5 类

生成文档前必须先确认体系（旧版 5 类 / 国标 25 类），再取骨架。本文件是骨架清单与代码策略的速查，具体章节树用 `arch.mjs docs <编号|简称> --spec gb` 获取。

> 本文件由 `npm run skill:refs` 从 `lib/` 数据源生成，**请勿手改**；要改内容请改数据源后重新生成。

## 代码策略档位

| 档位键 | 名称 | 规则 |
| --- | --- | --- |
| `none` | 禁止代码 | 只允许文字、表格、图；不得出现 \`\`\` 代码块。 |
| `commands` | 仅命令 | 允许命令行与操作步骤，不得出现编程语言语法。 |
| `signature` | 仅签名 | 允许接口签名/IDL/报文样例，不得出现函数体与类实现。 |
| `pseudocode` | 仅伪代码 | 允许 IF/THEN/LOOP 式伪代码并标注「伪代码，非交付源码」；不得出现可编译源码。 |
| `ddl` | 允许 DDL | 允许建表/索引/视图 DDL，不得出现业务逻辑代码。 |
| `data` | 仅测试数据 | 允许测试输入与预期输出数据，不得出现被测源码。 |
| `snippets` | 允许片段 | 允许调用序列与指令示例片段，不得给出完整可运行程序。 |
| `byref` | 只引用 | 只能用清单引用交付物，不得在正文内联源码。 |

「禁止代码」类文档出现 ``` 代码块即判不合格；「仅伪代码」必须标注「伪代码，非交付源码」。

## 裁剪建议（标准第 6 章允许剪裁）

| 项目规模 | 建议保留 |
| --- | --- |
| 小（< 5000 行 / 1~2 人） | FAR · SRS · SDD · STP · STR · SUM |
| 中（1~5 万行） | 再加 SDP · IRS · DBDD · STD · SCMP · DPMR · PDSR |

## 旧版 5 类 → 国标对应

| 旧版键 | 标题 | 国标对应 |
| --- | --- | --- |
| `arch` | 架构方案（方案/ADR） | FAR（可行性分析（研究）报告）做论证；系统级设计决策放 SSDD 第 3 章 |
| `prd` | 需求文档（PRD） | SRS（软件需求规格说明）；系统级需求再加 SSS，数据视角加 DRD |
| `hld` | 概要设计（HLD） | SSDD（系统/子系统设计（结构设计）说明）；纯软件项目用 SDD 第 3–4 章 |
| `lld` | 详细设计（LLD） | SDD（软件（结构）设计说明）第 5 章 CSCI详细设计；编程约定见 CPM |
| `dbd` | 数据库设计 | DBDD（数据库（顶层）设计说明） |

调用示例：`arch.mjs docs SRS --spec gb`、`arch.mjs docs prd --spec legacy`、`arch.mjs docs list`（两套对比）。
